# Ardit Portfolio

Personal portfolio built with React + TypeScript + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Analytics

The optional Supabase analytics setup is documented in [ANALYTICS.md](./ANALYTICS.md).
It is disabled when `VITE_ANALYTICS_ENDPOINT` is not set.
